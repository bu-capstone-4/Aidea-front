# Aidea 프로젝트 설명 문서

## 1. 프로젝트 개요

Aidea는 한 줄의 아이디어를 AI와 함께 기획 문서로 구체화하고, 팀원들이 실시간으로 함께 다듬은 뒤, 완성된 기획을 기반으로 AI가 할 일 목록(백로그)을 자동 생성해 그대로 관리할 수 있게 하는 협업 플랫폼이다. 대학생 팀 프로젝트나 사이드 프로젝트처럼 체계적인 기획 프로세스를 갖추기 어려운 소규모 팀을 주 대상으로 하며, "아이디어 → 기획 문서 → 백로그 → 작업 관리"를 하나의 워크스페이스에서 끊김 없이 이어주는 것이 핵심 가치다.

## 2. 타겟 사용자 및 페르소나

Aidea는 팀스페이스 단위로 OWNER(소유자) / MEMBER(멤버) / VIEWER(뷰어) 세 가지 역할을 구분하며, 이 권한 구조가 실제 페르소나와 자연스럽게 대응된다.

| 페르소나                           | 역할   | 목표                                                                              | 페인포인트                                                                                                  |
| ---------------------------------- | ------ | --------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------- |
| **강민석 (팀 리더)**               | OWNER  | 막연한 아이디어를 빠르게 기획으로 구체화하고, 팀을 꾸려 진행 상황을 관리하고 싶다 | 기획 문서 양식을 처음부터 잡는 데 시간이 오래 걸리고, 기획이 끝난 뒤 할 일 목록을 다시 손으로 정리해야 한다 |
| **한지원 (팀원 개발자)**           | MEMBER | 기획 문서에 의견을 더하고, 내가 맡은 작업을 명확히 파악해 진행하고 싶다           | 기획서가 어디 있는지, 최신본이 무엇인지 찾기 어렵고, 내 담당 작업이 명확히 정리되어 있지 않다               |
| **박지훈 (참관 멘토/외부 평가자)** | VIEWER | 팀의 기획과 진행 상황을 훼손 없이 확인하고 싶다                                   | 편집 권한까지 주면 실수로 내용을 건드릴 위험이 있고, 별도 보고 자료를 따로 받기도 번거롭다                  |

## 3. 페르소나 기반 유저 시나리오

### 시나리오 1 — 강민석(OWNER): 아이디어를 기획과 백로그로 완성하기

1. 랜딩 페이지에서 "무료로 시작하기"를 눌러 GitHub OAuth로 로그인한다.
2. 아직 소속된 팀스페이스가 없으므로 자동으로 팀스페이스 생성 화면으로 이동한다.
   - 1단계: 팀스페이스 이름과 핵심 아이디어를 입력하고, 필요한 기획 문서(필수: 아이디어 / 선택: 기획서·유저 시나리오·API 명세서·ERD)를 고른다.
   - 2단계: 함께할 팀원의 이메일을 입력해 초대를 보낸다(최대 8명).
3. 워크스페이스로 진입하면 사이드바에 선택했던 문서 목록이 보인다. 아이디어 문서를 열면 AI가 아이디어를 구체화하기 위한 질문을 먼저 던지고, 답변(또는 건너뛰기) 후 AI가 문서 초안을 자동으로 작성해 에디터에 채워준다.
4. 사이드바의 "추가하기"로 기획서·유저 시나리오 등 다른 문서를 추가 생성한다.
5. 작성된 문서에 대해 "AI 피드백"을 요청하면, AI가 논리적 허점이나 모호한 부분을 짚는 질문을 던지고, 수정 전/후 버전을 좌우로 비교해 보여준다. 마음에 들면 반영하고, 아니면 거부한다.
6. 헤더의 "백로그" 버튼을 눌러 백로그 설정으로 들어간다. 팀 구성(FE/BE 구분), 사용할 이슈 유형(에픽/스토리), 추가 필드(우선순위·스프린트·마감일)를 선택하고 "AI로 초안 생성"을 켜면, 지금까지 작성한 기획 문서를 바탕으로 AI가 Epic/Story/Task를 자동으로 만들어준다.
7. 생성된 백로그를 리스트 뷰 또는 보드(칸반) 뷰로 확인하며 담당자를 배정하고 우선순위·마감일을 조정한다.
8. 팀스페이스 드롭다운의 "멤버관리"에서 팀원의 역할을 멤버/뷰어로 조정하거나 새 팀원을 추가 초대한다.

### 시나리오 2 — 한지원(MEMBER): 초대받아 협업하고 내 작업 진행하기

1. 이메일로 받은 초대 링크를 클릭한다. 로그인 상태가 아니면 초대 토큰을 임시 저장한 뒤 GitHub 로그인으로 안내되고, 로그인이 끝나면 자동으로 초대가 수락되어 해당 문서로 이동한다.
2. 협업 에디터에서 다른 팀원의 커서와 이름을 실시간으로 보면서 같은 문서를 동시에 편집한다.
3. AI가 던진 구체화 질문 중 본인이 답할 항목에 답변하거나, 의견을 덧붙여 기획 내용을 다듬는다.
4. 백로그를 열어 보드 뷰에서 본인에게 배정된 태스크를 확인하고, 드래그 앤 드롭으로 상태를("할 일" → "진행 중" → "완료") 직접 옮긴다.
5. 작업이 끝나면 태스크를 완료 처리하고, 스토리의 진행률(완료 태스크 수/전체 태스크 수)이 자동으로 갱신되는 것을 확인한다.

### 시나리오 3 — 박지훈(VIEWER): 진행 상황 참관하기

1. OWNER로부터 VIEWER 권한으로 초대받아 팀스페이스에 합류한다.
2. 기획 문서를 열어도 에디터가 읽기 전용으로 표시되어 내용을 실수로 고칠 위험이 없다.
3. 백로그의 리스트/보드 뷰로 전체 진행 상황(이슈 개수, 진행 중/완료 비율)을 확인한다.
4. 멤버 관리 화면에서는 팀원 목록만 볼 수 있고, 초대 보내기나 역할 변경 같은 관리 기능은 노출되지 않는다.
5. 마음에 드는 결과물은 문서 내보내기로 Markdown 또는 PDF로 받아 별도로 보관한다.

## 4. 주요 기능

| 구분               | 기능                                                                                                                   |
| ------------------ | ---------------------------------------------------------------------------------------------------------------------- |
| 인증/팀 관리       | GitHub OAuth 로그인, 팀스페이스 생성, 이메일 초대(최대 8명), OWNER/MEMBER/VIEWER 역할 관리                             |
| AI 기획 지원       | 아이디어 1줄 입력 → AI의 구체화 질문 → 아이디어/기획서/유저 시나리오/API 명세서/ERD 초안 자동 생성                     |
| 실시간 협업 에디터 | BlockNote 기반 노션 스타일 에디터, Yjs CRDT 동시 편집, 실시간 커서/이름 표시, VIEWER 편집 차단                         |
| AI 문서 피드백     | 논리적 일관성·누락 내용·모호한 표현 분석, 수정 전/후 좌우 비교, 수락/거부 선택                                         |
| AI 백로그 생성     | 기획 문서 기반 Epic/Story/Task 초안 자동 생성, 팀 구성(FE/BE)·이슈 유형·추가 필드 커스터마이즈                         |
| 백로그 관리        | 리스트 뷰·보드(칸반) 뷰 전환, 상태별 필터링, 드래그 앤 드롭 상태 변경, 담당자/우선순위/스프린트/마감일 관리, 에픽 관리 |
| 실시간 프레즌스    | 온라인 멤버 표시, 누가 어떤 문서/백로그를 보고 있는지 실시간 공유                                                      |
| 문서 내보내기      | 완성된 기획 문서를 Markdown 또는 PDF로 다운로드                                                                        |

## 5. 화면 구성

| 화면                          | 경로                           | 설명                                                                                                                               |
| ----------------------------- | ------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------- |
| 랜딩 페이지                   | `/` (비로그인)                 | 서비스 소개, 주요 기능 카드, 4단계 워크플로우 안내, 로그인 유도                                                                    |
| 팀스페이스 생성 마법사        | `/create`                      | 1단계(팀 이름·아이디어·필요 문서 선택), 2단계(팀원 이메일 초대)                                                                    |
| 메인 워크스페이스             | `/main/:docId`                 | 좌측 사이드바(문서 목록·문서 추가), 상단 헤더(백로그·내보내기 버튼, 접속 중인 멤버), 중앙 협업 에디터                              |
| 문서 추가 모달                | 워크스페이스 내                | 문서 타입 선택 후 새 문서 생성                                                                                                     |
| AI 피드백 요청/질문-답변 패널 | 워크스페이스 내                | 추가 요청사항 입력 → AI 질문 응답 → 스플릿 뷰로 수정 전/후 비교                                                                    |
| 멤버 관리 모달                | 팀스페이스 드롭다운 내         | 멤버 목록·역할 변경·추방, 초대 대기 목록 관리, 신규 초대 발송                                                                      |
| 문서 내보내기 모달            | 워크스페이스 내                | Markdown/PDF 형식 선택 후 다운로드                                                                                                 |
| 백로그 모달                   | 워크스페이스 내(전체화면 모달) | 첫 진입 시 웰컴 화면 → 백로그 설정(AI 초안 생성 포함) → 리스트/보드 뷰 메인 화면(필터, 에픽 관리, 스토리/태스크/에픽 생성·수정 폼) |
| 초대 수락 페이지              | `/invite`                      | 초대 토큰 처리 후 로그인 유도 및 자동 수락                                                                                         |
